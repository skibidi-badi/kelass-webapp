Materi 01

Server di Proxmox dan Cara Menyiapkannya

Memahami konsep server, virtualisasi, dan langkah-langkah menyiapkan server menggunakan Proxmox VE.

Apa itu Server?

Server adalah komputer atau sistem yang dirancang untuk menyediakan layanan, data, atau sumber daya kepada komputer lain (yang disebut client) melalui jaringan.

Bayangkan server seperti sebuah restoran: pelanggan (client) datang dengan permintaan, dan restoran (server) memproses dan menyajikan apa yang diminta.

Fungsi Server
  • • Menyimpan dan mengelola data
  • • Menjalankan aplikasi web
  • • Mengelola database
  • • Menangani email
  • • Menyediakan layanan DNS
Jenis Server
  • • Web Server — menjalankan website
  • • Database Server — menyimpan data
  • • File Server — berbagi file
  • • Mail Server — mengelola email
  • • DNS Server — menerjemahkan domain

Apa itu Proxmox?

Proxmox Virtual Environment (VE) adalah platform virtualisasi sumber terbuka (open-source) yang memungkinkan kamu menjalankan beberapa Virtual Machine (VM) dan Container (LXC) pada satu server fisik.

Dengan Proxmox, satu server fisik bisa dipecah menjadi beberapa "server virtual" yang masing-masing berjalan independen.

Virtual Machine

Sistem operasi lengkap yang berjalan di atas server fisik dengan resource tersendiri.

Container / LXC

Lebih ringan dari VM, berbagi kernel dengan host tetapi tetap terisolasi.

Web Interface

Kelola semua VM dan container melalui browser tanpa perlu instalasi tambahan.

Gratis dan open-source — tidak perlu lisensi berbayar untuk penggunaan dasar

Web-based management — kelola server dari browser manapun

Support KVM dan LXC — dua teknologi virtualisasi dalam satu platform

Built-in backup, snapshot, dan clustering

Komunitas besar dan dokumentasi lengkap

Cara Menyiapkan Proxmox

1. Menyiapkan Hardware Server

Pastikan server memiliki minimal CPU dengan dukungan virtualisasi (Intel VT-x / AMD-V), RAM 4GB+, dan storage 50GB+.

2. Download Proxmox VE ISO

Unduh file ISO Proxmox dari proxmox.com/downloads sesuai versi terbaru.

3. Membuat Bootable USB

Gunakan tool seperti BalenaEtcher atau Rufus untuk menulis ISO ke USB flash drive.

4. Install Proxmox

Boot dari USB, ikuti wizard instalasi: pilih disk, atur timezone, set password root, dan konfigurasi jaringan.

5. Mengatur Jaringan

Konfigurasi IP address statis, subnet mask, gateway, dan DNS server agar Proxmox dapat diakses dari jaringan.

6. Login ke Web Interface

Buka browser dan akses https://ip-server:8006. Login dengan username root dan password yang sudah ditentukan.

7. Membat Virtual Machine

Klik "Create VM" → atur nama, OS (ISO), CPU core, RAM, dan disk size sesuai kebutuhan.

8. Install Sistem Operasi pada VM

Jalankan VM, buka console, dan install OS seperti Ubuntu Server melalui proses instalasi standar.

9 & 10. Mengatur Storage dan Network

Tambahkan storage jika diperlukan, lalu konfigurasi network bridge agar VM terhubung ke jaringan dengan IP tersendiri.

Mengkonfigurasi Server Docker, Container, dan Stack

Memahami Docker sebagai tools containerization, konsep container, dan bagaimana menjalankan multiple service dengan stack.

Apa itu Docker?

Docker adalah platform yang memungkinkan kamu mempackage aplikasi beserta semua dependensinya ke dalam sebuah container yang dapat berjalan di mana saja secara konsisten.

Dengan Docker, masalah "di komputerku jalan, di server tidak" bisa diminimalkan karena environment-nya sudah terstandarisasi.

Docker Image

Template read-only yang berisi OS, runtime, dan aplikasi. Seperti "blueprint" dari container.

Docker Container

Instance yang berjalan dari image. Seperti "rumah" yang dibangun dari blueprint.

Docker Hub

Registry publik untuk menyimpan dan membagikan Docker image.

Docker Compose

Tool untuk mendefinisikan dan menjalankan multiple container dengan satu file konfigurasi YAML. Sangat berguna untuk menjalankan aplikasi yang butuh beberapa service sekaligus.

Alur kerja Docker: dari Image ke Application

Dockerfile
Instruksi untuk membangun image
Docker Image
Template yang sudah di-build
Docker Container
Image yang sedang berjalan
Application
Aplikasi berjalan di dalam container

Apa itu Container?

Container seperti kotak terisolasi yang berisi aplikasi beserta semua kebutuhan untuk menjalankannya — library, config, dan dependency — dalam satu paket yang ringan.

⚡ Container
  • • Ringan dan cepat startup
  • • Berbagi kernel dengan host
  • • Ukuran kecil (MB)
  • • Isolasi proses
🖥️ Virtual Machine
  • • Lebih berat dan lambat startup
  • • Kernel sendiri (full OS)
  • • Ukuran besar (GB)
  • • Isolasi penuh (hardware level)

Apa itu Stack?

Stack (Docker Stack) adalah kumpulan beberapa service/container yang didefinisikan dalam satu file dan di-deploy bersamaan. Biasa digunakan dengan Docker Swarm.

Misalnya, sebuah website biasanya butuh web server, backend, database, dan reverse proxy — semuanya bisa dijalankan sebagai satu stack.

Konfigurasi Docker Server

1 Install Ubuntu Server & Update Package
Terminal
# Update package list
$ sudo apt update

# Upgrade existing packages
$ sudo apt upgrade -y
2 Install & Verifikasi Docker
Terminal
# Install Docker
$ sudo apt install docker.io -y

# Enable Docker on boot
$ sudo systemctl enable docker

# Start Docker service
$ sudo systemctl start docker

# Verify installation
$ docker --version
Docker version 27.x.x, build xxxxxxx
3 Menjalankan Container
Terminal
# Pull image dari Docker Hub
$ docker pull nginx:latest

# Jalankan container
$ docker run -d --name web-server -p 80:80 nginx

# Cek container yang berjalan
$ docker ps
4 Docker Compose
docker-compose.yml
version: "3.8"
services:
  web:
    image: nginx:alpine
    ports:
      - "80:80"
    restart: always

  db:
    image: mysql:8
    environment:
      MYSQL_ROOT_PASSWORD: secret_password
    volumes:
      - db_data:/var/lib/mysql
    restart: always

volumes:
  db_data:
Terminal
# Jalankan stack
$ docker compose up -d

# Cek status
$ docker compose ps

# Lihat logs
$ docker compose logs -f
5 Mengelola Container
Terminal
# Stop container
$ docker stop web-server

# Start container
$ docker start web-server

# Hapus container
$ docker rm web-server

# Lihat semua container (termasuk yang stopped)
$ docker ps -a

Cara Mendeploy Website ke Server dengan Domain my.id

Proses lengkap dari menyiapkan server hingga website dapat diakses publik melalui domain .my.id.

1 Menyiapkan Server

Gunakan Ubuntu Server yang sudah berjalan (bisa berupa VM di Proxmox atau VPS). Pastikan server memiliki akses internet dan IP publik.

Terminal
# Update server
$ sudo apt update && sudo apt upgrade -y

# Install Nginx
$ sudo apt install nginx -y

# Cek status Nginx
$ sudo systemctl status nginx

2 Upload Website

Ada beberapa metode untuk mengupload file website ke server:

Git

Clone repository langsung di server. Cara paling umum untuk proyek modern.

SCP

Copy file langsung dari komputer lokal ke server melalui SSH.

SFTP

Transfer file seperti FTP tapi lebih aman karena terenkripsi.

Terminal — Contoh Git
# Clone website ke server
$ git clone https://github.com/user/website.git /var/www/website

3 Mengatur Domain my.id

Domain adalah alamat website yang mudah diingat (contoh: contoh.my.id). DNS adalah sistem yang menerjemahkan domain menjadi IP address.

A Record adalah jenis DNS record yang menghubungkan domain langsung ke IP address server.

4 Konfigurasi Nginx

Buat file konfigurasi Nginx untuk domain kamu:

/etc/nginx/sites-available/contoh.my.id
server {
    listen 80;
    server_name contoh.my.id;

    root /var/www/website;
    index index.html index.htm;

    location / {
        try_files $uri $uri/ =404;
    }
}
Terminal — Aktifkan konfigurasi
# Buat symbolic link
$ sudo ln -s /etc/nginx/sites-available/contoh.my.id /etc/nginx/sites-enabled/

# Test konfigurasi
$ sudo nginx -t

# Restart Nginx
$ sudo systemctl restart nginx

5 SSL / HTTPS

HTTPS mengenkripsi data antara browser dan server. Tanpa HTTPS, data dikirim dalam bentuk teks biasa yang bisa diintercept. SSL/TLS adalah protokol yang membuat HTTPS bekerja.

Mengenal Ubuntu

Ubuntu sebagai sistem operasi server yang paling banyak digunakan di dunia — dari konsep dasar hingga penggunaan praktis.

Apa itu Ubuntu?

Ubuntu adalah sistem operasi berbasis Linux (khususnya Debian) yang dikembangkan oleh Canonical. Ubuntu tersedia dalam dua versi utama: Desktop (dengan GUI) dan Server (tanpa GUI, berbasis terminal).

Nama "Ubuntu" berasal dari bahasa Afrika yang berarti "kemanusiaan terhadap sesama" — mencerminkan filosofi open-source dan komunitas.

Stabil

Dirilis setiap 6 bulan dengan LTS (Long Term Support) setiap 2 tahun.

Open Source

Gratis digunakan, dimodifikasi, dan didistribusikan oleh siapa saja.

Komunitas Besar

Dokumentasi lengkap, forum aktif, dan banyak tutorial tersedia.

Package Management

APT memudahkan instalasi, update, dan removal software.

Cocok untuk Server

Ringan tanpa GUI, aman, dan dioptimalkan untuk server.

Paling Populer

Digunakan oleh mayoritas cloud server di dunia.

User dan Permission

root

Superuser dengan akses penuh ke semua file dan perintah. Bahaya jika digunakan sembarangan.

sudo

Menjalankan perintah satu kali sebagai root tanpa perlu switch user. Lebih aman.

Permission (rwx)

Setiap file memiliki 3 set permission: owner, group, others. Masing-masing bisa read (r), write (w), execute (x).

-rwxr-xr-- # owner: rwx | group: r-x | others: r--
chmod 755 file # rwx=7, r-x=5, r--=4
Terminal
# Buat user baru
$ sudo adduser deploy

# Tambahkan ke group sudo
$ sudo usermod -aG sudo deploy

# Ubah permission file
$ chmod 755 script.sh

# Ubah owner file
$ sudo chown deploy:deploy /var/www/website
